# UML Class Diagram Generator

React + TypeScript project structure for an interactive UML Class Diagram Generator.

## Main features to implement
- Create and edit UML classes
- Add attributes and methods
- Create class relationships
- Drag and arrange classes on a canvas
- Generate Java source code
- Preview Java code
- Copy/download generated Java files
- Save/load projects

## Suggested implementation order
1. package.json and Vite setup
2. uml.ts data models
3. UMLCanvas.tsx
4. UMLClassNode.tsx
5. Toolbar.tsx
6. PropertiesPanel.tsx
7. RelationshipPanel.tsx
8. javaGenerator.ts
9. CodeEditor.tsx
10. storage.ts
11. Editor.tsx
12. App.tsx and styling
